# 🔥 Truth or Drink

A simple, spicy party/drinking game — Would You Rather, Truth or Dare, and Truth or Drink — with a one-tap English/Spanish toggle.

Open `index.html` in a browser (or serve the folder with any static server / GitHub Pages). No build step, no dependencies.

- `index.html` — markup
- `style.css` — dark "hot" theme
- `app.js` — question/dare content (EN + ES) and game logic
- `manifest.json`, `sw.js`, `icons/` — installable home-screen app support

## Add to home screen

Once the site is served over `http`/`https` (e.g. GitHub Pages), open it on a phone:

- **iOS Safari:** Share → Add to Home Screen.
- **Android Chrome:** menu (⋮) → Add to Home screen / Install app.

It launches full-screen with its own icon, no browser chrome, and works offline after the first load.

18+. Play responsibly and respect consent.
